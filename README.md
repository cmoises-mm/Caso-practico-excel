# Contexto
Ejercicios practicos en excel con datos de la cafetería "CityBlend", ubicada en Nueva York, se han recopilado datos sobre las transacciones realizadas durante seis meses consecutivos, desde enero hasta junio. La cafetería cuenta con tres sucursales distintas

## Objetivo
poner en practica lo aprendido en el modulo de excel del curso analisis de datos con la transformación y visualización de los datos de manera que permita a los propietarios de la cafetería analizar patrones y detectar oportunidades de mejora para el negocio a partir de los datos recopilados.

## Resultado
los resultados de las consultas realizadas como ejercicios practicos se encuentran el el archivo excel dentro de este mismo repositorio
